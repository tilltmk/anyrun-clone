# AnyRun Clone - Interactive Malware Analysis Sandbox

A simplified clone of AnyRun built with Python Flask for interactive file analysis and sandboxing.

## Features

- 🔒 File Upload & Analysis
- 🖥️ Interactive Sandbox Sessions
- 📊 Real-time Analysis Dashboard
- 🔍 Behavioral Analysis & Monitoring
- 📸 Screenshot Capture
- 📝 Detailed Analysis Reports
- 🗄️ Session History & Management

## Installation

```bash
# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py
```

## Usage

1. Navigate to `http://localhost:5000`
2. Upload a file for analysis
3. View real-time analysis in the interactive sandbox
4. Review detailed reports and behavioral data

## Disclaimer

This is an educational project and a simplified clone. For production malware analysis, use proper isolation and security measures.
