Step 2: Network Configuration

An isolated network is required for safe malware analysis. This network will be created automatically.

Step 3: Select ISO Image

Select a Windows or Linux ISO to create a VM template for dynamic analysis. The system will search common directories for ISO files.

Step 4: Complete OS Installation

Important: You need to complete the OS installation via VNC. After installation, install the QEMU Guest Agent for best results.
Installation Tips:
  • Create a user named "Sandbox" for Windows
  • Enable Remote Desktop or WinRM for remote execution
  • Install QEMU Guest Agent from virtio drivers
  • Disable Windows Updates and Defender for analysis
